# Security policy

Please report vulnerabilities privately rather than in a public issue.

- Preferred: [report a vulnerability](https://github.com/cerredz/vidbyte-cli/security/advisories/new)
  through GitHub's private reporting.
- Or email contact@vidbyte.pro with the subject "vidbyte-cli security".

Include the `vidbyte-cli --version` output, your OS, and steps to reproduce. Never include API
keys, private keys, or other secrets in a report.
